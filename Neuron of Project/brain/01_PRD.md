# 01 PRD: Smart Campus Management System

## Product name
CampusFlow

## Product vision
A modern campus operations platform that centralizes students, faculty, departments, courses, enrollment, attendance, assignments, grades, notifications, and administrative reporting.

## Primary users
- Student
- Faculty
- Administrator

## MVP
1. Authentication
2. User profiles
3. Departments
4. Courses
5. Enrollment
6. Attendance
7. Assignments
8. Submissions
9. Grades
10. Notifications
11. Admin dashboard
12. Search, filtering, pagination
13. API documentation
14. Tests
15. Dockerized local environment

## Later/optional
- Redis caching
- Real-time notifications
- WebSocket events
- AI academic assistant
- Attendance risk insights
- Email integration
- Audit log
- Advanced analytics

## Product principles
- Secure by default
- Simple domain model
- Clear permissions
- Consistent APIs
- Accessible UI
- Explainable AI features
- Learning before complexity

## Success criteria
The learner can explain:
- request lifecycle
- dependency injection
- controller/service/repository responsibilities
- JPA relationships
- DTOs
- validation
- global exception handling
- JWT authentication
- authorization
- transactions
- pagination
- caching
- testing
- Docker deployment

## Explicit non-goals
- No React/Next.js frontend
- No microservices initially
- No Kubernetes initially
- No production payment system
- No unnecessary AI features
